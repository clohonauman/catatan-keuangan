============================================================
4A. KONFIGURASI EMAIL PEMULIHAN (WAJIB UNTUK RESET EMAIL)
============================================================

File konfigurasi:
mail_config.php

Aplikasi mendukung dua metode:

A. PHP mail()
--------------
Set:
MAIL_TRANSPORT = 'mail'

Metode ini hanya bekerja jika server/hosting mengizinkan fungsi mail().
Pastikan MAIL_FROM_EMAIL menggunakan alamat pengirim yang valid.

B. SMTP
-------
Set:
MAIL_TRANSPORT = 'smtp'
MAIL_SMTP_HOST = host SMTP
MAIL_SMTP_PORT = port SMTP
MAIL_SMTP_USERNAME = username/email SMTP
MAIL_SMTP_PASSWORD = password / app password SMTP
MAIL_SMTP_ENCRYPTION = tls, ssl, atau none
MAIL_FROM_EMAIL = alamat pengirim
MAIL_FROM_NAME = Catatan Keuangan

Contoh umum TLS:
MAIL_SMTP_PORT = 587
MAIL_SMTP_ENCRYPTION = 'tls'

Contoh umum SSL:
MAIL_SMTP_PORT = 465
MAIL_SMTP_ENCRYPTION = 'ssl'

JANGAN unggah kredensial SMTP ke repository publik.
Gunakan App Password jika penyedia email mewajibkannya.

============================================================
28. ERROR 500
============================================================

Periksa PHP error log.

Penyebab umum:
- file belum ter-upload lengkap
- function helper hilang
- permission data
- JSON rusak
- PHP terlalu lama
- syntax error
- disk quota
- file upload problem

Pastikan PHP >= 7.4.

Rekomendasi PHP 8.1/8.2.
